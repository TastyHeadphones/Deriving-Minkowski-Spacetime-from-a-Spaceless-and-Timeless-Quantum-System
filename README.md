# Deriving Minkowski Spacetime from a Spaceless and Timeless Quantum System

Can finite quantum data, with no assigned spacetime or clock, determine a calibrated four-dimensional Minkowski geometry?

The initial result is an underdetermination theorem for a specific correlation reconstruction. Every finite simple graph can be recovered as the positive pairwise mutual-information support of a separable diagonal quantum state. Path and triangle instances give distinct reconstructed relations under the same assumptions at fixed local dimension. Explicit scaling families give different continuum dimensions. A derivation of Minkowski spacetime under stronger independent assumptions remains open.

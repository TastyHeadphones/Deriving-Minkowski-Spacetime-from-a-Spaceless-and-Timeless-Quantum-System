# Countermodels and rejected inferences

| ID | Model | Rejected inference |
|---|---|---|
| C1 | Scalar Hilbert space, unique state | Finite quantum kinematics always provides distinguishable operational events. |
| C2 | Path and triangle on three labels, using the same fair-bit preparation rule | Positive mutual information selects a unique connected relation at fixed subsystem count and dimension. |
| C3 | An isolated label and a correlated pair | Positive correlation always gives a finite distance between distinct labels. |
| C4 | One common model family with integer lattice graphs of rank 1, 2, 3 or 4 | The preparation and shortest-walk rules select dimension three, even in a controlled limit. |
| C5 | Maximally mixed state and identity clock transition | A finite constrained state must have nontrivial clock or modular flow. |
| C6 | Bell-state local trace-preserving interventions | Entanglement alone is a controllable signalling resource. |
| C7 | Identity, unrestricted, or sector-dependent circuit routing | The same quantum kinematics sets a universal finite speed. |
| C8 | Positive conformal scalings and the spacelike translation quotient of flat spacetime | Null cones fix calibrated interval values, or local flatness fixes global topology. |

C2 has a Lean token-support and nonisomorphism witness. C3, C4 and C6 also have executable checks. C7 compares optional dynamical completions. Full model scope and proofs appear in the paper.

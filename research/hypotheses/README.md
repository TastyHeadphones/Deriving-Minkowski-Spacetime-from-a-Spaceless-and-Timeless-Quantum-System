# Open problems

The machine-readable list is in registry/conjectures.json. A first tractable problem is to prove a robust reconstruction theorem for noisy endpoint states under a specified threshold. A useful result would relate uniform trace-distance errors of the pair marginals to the recovered edge set, with dependence on local Hilbert dimension explicit. A statement about an entire projective scaling family would need a uniform stability hypothesis. This problem does not presume that any of the limiting metrics is Lorentzian.

# Contributing

Describe the scientific claim, its smallest assumption set and an explicit failure case. For a proof change, update Lean, the registry and the matching analytic explanation. For an experiment, check known limiting cases and record the seed and configuration. Submit new hypotheses as open entries. Include primary source identifiers and say when a reference has not been checked directly.

Use the verification steps in REPRODUCIBILITY.md. A pull request should identify any conditional results or claims that remain analytic. Preserve the recorded history of corrections and failed hypotheses.
